# Tesseract

Tesseract is a *Flappy Bird*-style game with a techno / space arcade
aesthetic, developed in C++ with [raylib](https://www.raylib.com/).

You control a ship that must fly through the gaps in the obstacles
coming from the right. Avoid collisions and try to survive as long as
possible.

The game supports both single-player and local two-player modes, where
two players compete simultaneously.

> Assignment for **Práctica Profesional I: Desarrollo de Videojuegos
> I**, Image Campus, 2026.

## Current version: 1.0

-   Single-player and local two-player game modes.
-   Two controllable ships, each with its own controls.
-   Gravity and jump mechanics.
-   Two-part obstacles (top and bottom) with a gap.
-   Collision detection and Game Over conditions.
-   Two-player victory system: the surviving player wins. If both
    players lose, the result is a draw.
-   Main menu with options to play with one or two players, view the
    tutorial, view the credits and exit.
-   Tutorial screen with the controls for both players.
-   Credits screen.
-   Parallax background with multiple layers.
-   Techno / space-inspired visual style and custom color palette.
-   Music tracks and sound effects.
-   After a Game Over you can retry, and you can return to the menu at
    any time during a run.

## Controls

  Key          Action
  ------------ ----------------------
  Space        Player 1: jump
  Up Arrow     Player 2: jump
  Enter        Retry after losing
  Esc          Return to the menu
  Left click   Select a menu option
